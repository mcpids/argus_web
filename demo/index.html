DEMO MODE · LOCAL & SYNTHETIC

See it react.

Demo mode makes your local Paart install react to realistic, synthetic AI-agent activity, so you can watch detection, classification, and enforcement happen end to end without wiring up real traffic. Everything runs on your own machine. Nothing leaves it.

HOW IT WORKS

Scripted scenarios, real pipeline.

When you switch demo mode on in Settings, the local daemon replays a set of scripted scenarios through the same inspection pipeline that handles live traffic, emitting genuine events, detections, and approval requests into your local database over 30–60 seconds each. The Console you already have open lights up with agents, verdicts, alerts, and pending approvals you can act on. It's the fastest way to understand what Paart does before pointing real tools at it.

THE SCENARIOS

Five, one per thing Paart catches.

GOOD

A registered, well-behaved enterprise agent doing normal work. The baseline: clean traffic, allowed verdicts, healthy status.

INJECTED

A prompt-injection attempt riding inside a tool call. Watch the pattern engine flag it and the pipeline raise a high-severity detection.

SHADOW

An unregistered agent IT has never seen, discovered by fingerprinting and auto-classified as a shadow agent on the Agents page.

FAKED

An agent spoofing a trusted identity. Surfaces how fingerprint mismatch escalates risk toward suspicious / malicious tiering.

APPROVED

A human-in-the-loop flow: a sensitive call triggers a require_approval verdict and shows up under Approvals, where you Approve or Deny and see the decision recorded.

TURNING IT ON

Two clicks, fully reversible.

  1. 01Install Paart and let the daemon start. Open the Console (the native app window, or localhost:3000 in a browser).
  2. 02Go to Settings and toggle Demo mode on. Scenarios begin emitting into your local instance.
  3. 03Watch the Dashboard, Detections, Agents, and Approvals pages populate. Toggle demo mode off whenever you're done, it stops immediately and the synthetic data is clearly marked.

It's local and safe. Demo mode generates synthetic events on your own machine and sends nothing to Cognifinity. It's for exploration only. Turn it off before running Paart against real traffic so your dashboards reflect reality. See how Paart handles your data.
