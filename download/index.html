AFTER INSTALL

Try demo mode

Once the daemon is running, open the Console and turn on Demo mode in Settings. Paart replays scripted scenarios (GOOD, INJECTED, SHADOW, FAKED, APPROVED) through the real inspection pipeline, emitting events into your local instance over 30–60 seconds each, so you can see detection and enforcement before pointing real tools at it. It's local and synthetic; nothing leaves your machine. Learn more.

SOMETHING WRONG?

Need an air-gapped tarball, an SBOM, or a pilot conversation?

Both desktop installers are signed. macOS is Developer ID signed, notarized and stapled, so it opens without a Gatekeeper prompt. Windows is Authenticode signed (SSL.com OV, RFC-3161 timestamped); SmartScreen may still prompt until the certificate builds reputation. Checksums for every artifact are published above, and you can verify the signatures yourself before installing.
