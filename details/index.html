Behind the scenes

How the parts work together

01/Gateway

Request checks

Checks connected tool requests. MCP is pilot-tested; OpenAI and Anthropic support is experimental.

02/API

Shared rules

Manages rules, approval requests, and activity records.

03/Sentinel

Tool discovery

Discovers local tool configurations. Automatic process wrapping is not shipped. Kernel monitoring is (planned).

04/Cortex

Content checks

Looks for known harmful instruction patterns. More advanced classification is experimental.

05/Console

Your dashboard

Review activity, change rules, and approve or deny requests.

Your options

Choose what happens next.

Rules can let a request proceed, stop it, or ask for approval. Each decision is recorded.

Allow

Let the request continue.

Observe

Let it continue and flag it for review.

Hide tool

Remove a tool from the available list.

Remove data

Remove matched sensitive information.

Ask a person

Hold the request for a person’s decision.

Block

Stop the request and return an error.

Stop session

Stop this session at the Paart gateway.
